## Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, customer segments, product performance, discounts, subscriptions, shipping preferences, and revenue contribution.

The project uses **Python, SQL, and Power BI** to transform raw customer transaction data into meaningful business insights and an interactive dashboard.

---

## Objectives

* Understand customer purchasing behavior
* Analyze revenue across customer demographics
* Identify high-performing products and categories
* Analyze customer loyalty and previous purchases
* Evaluate subscription behavior
* Understand the impact of discounts and shipping methods
* Build an interactive Power BI dashboard for business reporting

---

## Tools & Technologies

* **Python** – Data cleaning, transformation and exploratory analysis
* **Pandas** – Data manipulation and preprocessing
* **MySQL** – SQL-based business analysis
* **Power BI** – Interactive dashboard and visualization

## Dataset

The dataset contains **3,900 customer purchase records** with 18 attributes covering:

* Customer demographics
* Products purchased
* Product categories
* Purchase amount
* Location
* Season
* Review ratings
* Subscription status
* Shipping type
* Discounts
* Previous purchases
* Payment methods
* Purchase frequency

---

## Project Workflow

### 1. Data Loading & Exploration

The dataset was loaded into Python using Pandas.

Initial analysis included:

* Dataset structure and data types
* Descriptive statistics
* Missing-value identification
* Categorical variable exploration
* Distribution of customer and purchase attributes

### 2. Data Cleaning & Transformation

The following preprocessing steps were performed:

* Missing **Review Rating** values were imputed using the median rating within each product category.
* Column names were standardized to lowercase and converted to underscore-separated format.
* `Purchase Amount (USD)` was renamed to `purchase_amount`.
* Customers were grouped into four age groups using quartiles:

  * Young Adult
  * Adult
  * Middle-aged
  * Senior
* Purchase frequency categories were converted into approximate purchase intervals in days.
* `Promo Code Used` was removed after checking that it contained the same information as `Discount Applied`.

### 3. SQL Analysis

The cleaned dataset was loaded into MySQL for business-focused analysis.

Key SQL questions included:

* Revenue generated by gender
* Customers using discounts while spending above average
* Top-rated products
* Average purchase amount by shipping type
* Subscriber vs. non-subscriber spending
* Products with the highest discount rates
* Customer segmentation based on previous purchases
* Top products within each category
* Subscription behavior among repeat buyers
* Revenue contribution by age group

SQL concepts used include:

* `GROUP BY`
* Aggregate functions
* `CASE WHEN`
* Subqueries
* CTEs
* `ROW_NUMBER()`
* Filtering and sorting

## Key Insights

### Revenue

* Total revenue in the dataset is approximately **$233K**.
* Male customers contributed approximately **$157.9K**, compared with **$75.2K** from female customers.
* Clothing generated the highest revenue among the four product categories.

### Customer Loyalty

Customers were segmented based on previous purchases:

* **New:** 83 customers
* **Returning:** 701 customers
* **Loyal:** 3,116 customers

The dataset therefore contains a substantially larger loyal-customer segment.

### Subscription Behavior

* 1,053 customers were subscribers.
* 2,847 customers were non-subscribers.
* Average purchase value was very similar between subscribers and non-subscribers.

This suggests that subscription status did not create a major difference in average transaction value in this dataset.

### Product Performance

The five products with the highest average review ratings were:

1. Gloves
2. Sandals
3. Boots
4. Hat
5. Skirt

### Discounts

Products with the highest percentage of purchases where discounts were applied included:

* Hat
* Sneakers
* Coat
* Sweater
* Pants

### Shipping

Among Standard and Express shipping:

* Express average purchase: **$60.48**
* Standard average purchase: **$58.46**

Express-shipping customers had a slightly higher average purchase amount.
